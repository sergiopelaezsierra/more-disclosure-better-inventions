# Replication package — "More Disclosure, Better Inventions? Commercial Potential in University Invention Disclosures"

This package contains the code, ancillary public data, and trained-model
artifacts needed to reproduce the tables and figures of the paper. Some
inputs are confidential or licensed and are therefore **not** redistributed
here — see [`DATA_AVAILABILITY.md`](DATA_AVAILABILITY.md) for what those
are and how to obtain them.

**Repository:** <https://github.com/sergiopelaezsierra/more-disclosure-better-inventions>
**Code archive (Zenodo):** *DOI pending — minted on the first tagged release.*
**Trained SciBERT models (Zenodo):** [10.5281/zenodo.20184929](https://doi.org/10.5281/zenodo.20184929)

## Reproducing the paper

### Quick path (when the analytical dataset is in place)

1. Place the analytical dataset (`7_disclosure_otl_and_pubs_wos_matched_with_predictions.csv`)
   somewhere on disk. The default-relative path is
   `../Data/Processed/7_disclosure_otl_and_pubs_wos_matched_with_predictions.csv`
   (one level up from this folder). Override via the environment variable
   `REPL_DATA_ANALYTICAL`.
2. For Figure 4, place the AUTM Licensing Survey CSV at
   `../Data/AUTM Survey/AUTM_1991_2023_survey.csv` (or `REPL_DATA_AUTM`),
   and set the environment variable `REPL_FOCAL_INSTITUTION_REGEX` to a
   regex that picks out all spelling variants of the focal university in
   the AUTM `INSTITUTION` column. The script intentionally has no default
   for that regex so the focal institution is not hard-coded in the public
   package. For example, on Unix shells:
   ```
   export REPL_FOCAL_INSTITUTION_REGEX='^My University.*$'
   ```
3. Run every paper-output script:

   ```bash
   for f in code/03_paper_outputs/03*.R; do
     Rscript "$f"
   done
   ```

   Each script saves its output to `outputs/tables/` or `outputs/figures/`
   and prints the numeric content to the terminal so you can verify
   matches against the manuscript.

### Full path (when you only have raw inputs)

This requires the **confidential** OTL exports and a **licensed** WoS
export — see `DATA_AVAILABILITY.md`. The full pipeline is:

```
code/01_build_analytical_dataset/01c_fix_fy25_otl.R   (only if FY25 split)
code/01_build_analytical_dataset/01a_clean_wos.R
code/01_build_analytical_dataset/01b_merge_otl.R
code/01_build_analytical_dataset/01d_match_otl_wos.py
code/02_apply_cp_measure/02_score_publications.py
code/03_paper_outputs/03*.R          (paper artifacts)
```

The matching and scoring steps require a GPU for tractable runtime
(~30 minutes total on a single T4 GPU for the focal-university dataset of
~32k publications).

### Retraining the commercial-potential models (optional)

See `code/04_retrain_cp_models_optional/README.md`. You do **not** need to
run this unless you wish to recompute the measure from scratch. The
pre-trained models are deposited externally (see `DATA_AVAILABILITY.md`).

## Anonymization note

The paper anonymizes the focal university (referred to as "a major U.S.
engineering university"). Inputs that originated in the institution's
Office of Technology Licensing retain internal column names but contain no
personally identifying information beyond inventor full names — which are
also present in Web of Science records and are therefore not redacted by
the OTL. None of those inputs is shipped in this package.
